Comparison scope

Three plans support the same review outcome

Each plan reviews documents, runs domain analysis, and produces an evidence-backed result. The plans differ in who controls the workflow.

Comparison dimensions

  • Orchestration and task assignment
  • Tools, skills, and context boundaries
  • Evidence and coverage validation
  • Runtime shape and implementation work
The deck compares designs without selecting one

Review invariants

A valid result must prove more than good prose

01

Coverage

The run settles every file in the immutable manifest.

02

Analysis

Every mandatory domain check leaves a receipt.

03

Evidence

Each retained claim can reopen the exact source location.

04

Completion

The service publishes one validated artifact bundle or fails clearly.

These invariants belong in code. A model can propose findings, but it cannot waive a missing source or invalid citation.

Runtime guardrails

  • task_id acts as the idempotency key.
  • The host rejects duplicate or changed assignments.
  • Children receive no run_specialist tool.
  • The final validator rejects missing required delegations.
Domain specialists, not file-format agents
File formats stay behind document adapters. Domain agents can reconcile evidence across CSV, Excel, PDF, and DOCX.

Agent implementation

  • Complete bounded review tool catalog
  • Context and middleware limits
  • Structured output and post-loop checks
